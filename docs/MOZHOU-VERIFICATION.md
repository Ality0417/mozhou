# 墨舟验证记录

验证日期：2026-10-14。交付对象为可复现源码增量，不是正式签名安装包。底座与 MIT 来源见 [项目说明](../README.md)。

## 已验证的能力

- 书籍级简体／繁体／英文写作档案，独立继承与保存，切换语言回算当前正文计数。
- 中文按汉字、英文按近似词计数。真实 CodeMirror 事务覆盖逐字输入、替换以及程序写入不计作人工贡献。
- TXT／Markdown／DOCX／EPUB 的长中英文原文、章尾、XML 字符及章节顺序完整，默认不夹带内部灵感。
- 档案保存重复提交、失败重试、在途禁用，以及切书后迟到回包不覆盖新草稿。
- AI 事实先待确认，确认／拒绝的归属校验与竞态保护；未确认项不进入已确认事实提示。
- 审核与正文／任务单一致性，正文变化清除旧分数。修订额度跨入口最多两轮，失败保留消耗，旧债务不能改写未重新审核的正文。
- 原创固定样例：英文奇幻冒险、中文都市悬疑。没有使用外部小说或用户作品。

## 安全维护与剩余告警

本轮保留原有生产及全依赖审计门禁，没有忽略公告或跳过检查。使用官方注册表发布版本修复已知高危／严重依赖问题，版本依据与迁移见 [决策日志](decision-log.md)。

完整依赖树尚有一个中危 [sprintf-js 精度参数拒绝服务公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)，当前公告未给出修复版本。路径为 electron-builder → app-builder-lib → @electron/get → global-agent → roarr → sprintf-js，属于构建工具日志依赖，不在生产依赖审计内。不能据此宣称软件不存在安全风险。

## 未通过或尚未验证

- Windows 安装包：Linux 交叉打包曾运行到 NSIS 阶段，但缺少 Wine（spawn wine ENOENT），未完成安装包交付。安全更新后的桌面安装包仍待 Windows 构建与实机验收；不能把 pnpm build 成功视为打包通过。
- 桌面视觉验收／截图：浏览器启动被当前运行环境的 Unix socket 限制阻止，未绕过限制。组件测试不代替真实窗口视觉验收；亦未验证 macOS／Linux 安装包。
- 真实模型：未配置个人密钥、未调用付费接口；未评估长篇连贯性、文笔、真实模型耗时／成本或平台通过率。本轮没有训练模型权重。
- 平台适配：只有通用可配置编辑／导出档案，未宣称符合任何具体国家或平台的最新投稿／AI 披露规则，不自动上传发布。
- 审核覆盖：长于 8,000 字符的去 AI 味改写明确跳过以免截断章尾；团队审核当前仅覆盖前 6,000 字符。世界观等广义规划修改后的审核失效尚未全面覆盖，重要设定调整后应主动重新审核。
- 旧版未记录过的自动改稿次数无法追溯；损坏或未结算修订记录会停止继续自动修订，需作者检查。
- GitHub 源码上传、指定提交的远程 CI 与正式发布状态应单独核实，不由本地测试结果推断。

当前不提供常驻公网服务，应用是本地优先桌面工作台。正式发布前还需补齐各平台安装验收与真实模型样章评测。
